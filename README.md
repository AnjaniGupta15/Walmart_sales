# 🛒 Walmart Sales Analysis

## 📌 Project Overview
An end-to-end data analysis project on Walmart sales data using **Python and MySQL**. The project focuses on data cleaning, analysis, and SQL-based business insights.

## 🛠️ Tools & Technologies
- Python
- Pandas
- MySQL

## 🔄 Project Workflow
1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis
4. Data Analysis using Python
5. SQL Queries & Business Analysis
6. Insights & Conclusions

## 📊 Key Analysis
- Sales and revenue analysis
- Product/category performance
- Branch-wise sales analysis
- Payment method analysis
- Customer buying patterns
- Sales trends

## 📁 Project Files
- `project.ipynb` — Python analysis
- `walmart_sql.sql` — MySQL queries
- `requirements.txt` — Required libraries

## 🎯 Objective
To analyze Walmart sales data and extract meaningful business insights that can support **data-driven decision making**.

## 📚 Data Source
Walmart Sales Dataset — Kaggle
